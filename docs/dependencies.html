ssh-snakehole specification / 2. Dependencies and ports

Borrow protocols; account for the implementation

Import policy

The target runtime consists of standard Python, ssh_snakehole, and an audited WebSocket stack. Prefer wsproto and its pure Python HTTP dependency h11 to writing another WebSocket parser. Their networking adapter belongs in this package and uses asyncio streams. Both dependencies must pass a complete source/import audit at the release versions selected. No dependency can silently choose an optional accelerator. The runtime wheel metadata must list only these approved packages.

Vendor the small, modified SPAKE2 and curve code under ssh_snakehole/_crypto with original notices and a provenance record. This makes the changed HKDF dependency explicit and avoids shipping a confusing modified upstream distribution. The package does not vendor an entire SSH framework or unrelated Wormhole CLI. There is one concrete transport and one SSH engine. Do not create plug-in registries or speculative backend abstractions.

py3-none-any is necessary packaging metadata, but insufficient evidence. Audit wheel contents for native code and executables, follow every runtime import recursively, inspect optional imports, and install in a clean environment where native crypto packages are absent. Development tools and independent interoperability test peers may use native libraries; they must not leak into runtime metadata or offline artifacts.

Additional native cryptographic operations are not hidden in ssl. Its public API supplies TLS connections, not arbitrary Ed25519 signing, X25519 multiplication or the OpenSSH cipher. Those ports remain necessary. Do not invoke private OpenSSL functions to avoid implementing them.

What an exact Iroh port would mean

Exact Iroh behavior would require a separate scope: QUIC packet and stream processing, TLS handshake integration for QUIC, congestion/loss/retransmission machinery, UDP socket behavior, NAT discovery and hole punching, relay/discovery authentication, endpoint identity and network migration. The audited Rust lockfile includes multiple TLS/crypto and QUIC packages; lockfile presence alone does not prove every path executes. The used feature is an authenticated bidirectional transport, so Transit is the focused replacement.

Replacing Iroh changes relay bandwidth use and connection success on networks that block the Transit relay port. Our release must publish observed network coverage. No claim of identical NAT traversal follows from both systems being able to use a relay.

Licensing and provenance

Proposed original package license is MIT. MIT notices from ported Wormhole/SPAKE/group code must accompany source and offline artifacts. OpenSSH files have file-specific permissive notices; libsodium includes ISC-licensed code and other notices. Check each selected file rather than inferring a blanket license from repository metadata. Translations retain attribution. Standards test-vector and extracted-code terms must also be recorded.

Every port record MUST include upstream repository, immutable revision, original path, license, which functions were retained, which changes were made, and tests proving behavior. Include a hash of each original input file and the translated output when the implementation exists. This specification does not fabricate those output hashes. Upstream security fixes require an explicit review; no automatic update may change cryptographic behavior unreviewed.

The machine-readable ledger is the complete audited dependency map for the current Go manifest plus the relevant helper/runtime candidates. Implementation must add selected Python package versions and the recursively audited h11 graph before release.
