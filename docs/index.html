ssh-snakehole / 0.5.1 / 8 October 2026

Temporary SSH as a Python package

Open a foreground host, share its one-use code, open the remote shell, run commands or transfer files, then close access. Pairing creates a separate secret token for encrypted local reconnection. Neither secret is saved.

Access expires after 30 minutes of inactivity. Active commands, interactive shells and file transfers pause that timer. Both computers connect outward, then try UDP hole punching using ICE. SSH uses a reliable WebRTC data channel when direct routing works, with relay fallback otherwise. No router configuration is needed.

This is a work in progress. Install from GitHub or a checkout with pip; public PyPI release is deferred. No service, custom installer or PATH edit is added.
