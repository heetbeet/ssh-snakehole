ssh-snakehole / 0.2.1 / 7 October 2026

Temporary SSH, installed as a Python package

A foreground Python process prints a one-use code. The operator redeems it, gains authenticated SSH command and SFTP access as the host account, then closes access. Both computers make outbound connections; no router configuration is required.

The current design uses AsyncSSH, cryptography, PyNaCl and upstream spake2. Python's ordinary pip and venv tools provide installation, including offline wheel installation. Run python -m ssh_snakehole open.
