Research findings that changed the design

  • Magic Wormhole's Python distribution includes native crypto dependencies; its usable protocol remains a good foundation.
  • The SPAKE2 group's Python arithmetic can be retained while replacing its HKDF import with permitted standard Python.
  • Transit supports a bidirectional stream for SSH, which avoids reproducing QUIC solely to carry commands and files.
  • Reference mailbox WebSocket framing disagrees with the document's binary framing description. Interoperability follows the inspected client, and tests cover both.
  • python-pure25519's sample DH is not interoperable X25519. Similar curve names are not a substitute for the SSH profile.
  • Stdlib ssl handles TLS after the user's clarification. A separate TLS/certificate port would be unnecessary scope.
  • Standard ctypes permits Python wrappers around built-in OS security/process APIs, so Windows token/ACL/Job Objects can be specified without pywin32. Loading third-party native crypto/transport code remains excluded.
