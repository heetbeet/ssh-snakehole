ssh-snakehole / implementation 0.1.0 / 7 October 2026

Working implementation and its evidence

The repository now contains an importable client/server, CLI, optional relay, source-only wheel, bundled zipapp and offline installer. It follows the researched architecture: stdlib TLS, wsproto/h11 framing, Python SPAKE2/SecretBox/Ed25519/X25519/ChaCha20-Poly1305, actual SSH v2 and SFTP v3. Native cryptographic libraries and SSH executables appear only in development interoperability checks.

Platforms

Windows x64 and Linux x64 Ubuntu 24.04 in WSL, both CPython 3.12.14, have run the pipeline suite as non-admin accounts. The Linux run uses only the bundled source archive plus Python's standard library. A nine-cell CI workflow is supplied for Python 3.12–3.14 on Windows/Linux/macOS, but has not been run remotely. Tests requiring a user host skip elevated accounts, visibly. macOS, ARM64, Python 3.13/3.14 and protected admin installations remain unverified cells.

The older Ubuntu CPython 3.12.3 build intermittently raised impossible list-index errors and crashed during parallel cipher stress. Its precise upstream cause is unresolved. This release requires CPython 3.12.14 or newer, through 3.14. The tested 3.12.14 build passed 100 random parallel SSH-cipher round trips and eight repeated complete TCP workflows.

Concrete boundaries

No PTY, interactive SSH shell, forwarding, agent forwarding, arbitrary SSH algorithms, direct listeners or Iroh compatibility is implemented. The API uses command execution and SFTP. Mailbox hashcash is limited to 22 bits and 30 seconds of work. HTTP proxies are unsupported. Default public Transit TCP 4001 requires that outbound port to be reachable. WebSocket Transit is supported with an explicit relay URL, without a silently chosen public fallback.

Network channel credit is bounded to 64 retained channels per process, 256 KiB each across stdout/stderr. A locally initiated rekey temporarily defers up to 256 KiB of already-in-flight packets, then rejects further excess. Captured output has a separate 8 MiB default cap. Host connections are capped at eight and channels at sixteen per SSH connection. Files use bounded 32 KiB data chunks and source-only crypto runs off the network loop.

Cancellation finishes the current bounded filesystem operation before closing its handle. Network/command loss never retries an operation. If a remote commit reply is lost, a transfer's commit status is unknown. Fsync confirms file contents were requested to flush; it is not a promise about directory-entry persistence through power loss. Regular-file SFTP handles exclude device files and FIFOs.

Admin mode is manually launched with python -I from a protected installation and does not self-elevate. Windows token/ACL checks fail closed. The user installer creates no protected admin installation. POSIX groups and the pipe watcher are process-lifetime measures, not containment against a deliberately hostile operator. The same watcher code runs on Linux/macOS; macOS native lifecycle validation remains pending.

Release status

Independent crypto/security review, separate-NAT and macOS evidence, sustained 2 GiB memory/performance testing, protected-admin lifecycle testing and GitHub publication remain release gates. The project must not be described as audited or production ready. Root boot scripts contain the intended release URL; it is not available until a repository and release are explicitly published.

The earlier specification remains the target. This page records current scope and explicit deviations: optional direct listeners and the broader platform/performance gates remain unmet; command names use actual encrypted ticket IDs rather than a separate alias layer. SFTP uses a smaller 64 KiB packet/32 KiB chunk limit and one outstanding client request; standard non-replacing rename is limited to regular files, with posix-rename supporting directory replacement. File policies currently enable or disable SFTP, and string paths are the supported library surface. Pipe cleanup drains for up to five seconds. Unix installation uses one marked profile line, and native export can use a secret environment passphrase. No placeholder API or silent native dependency fills a gap.

Reproduce with python -m unittest discover -s tests -v and python tools/build.py. Independent development checks are tools/reference_crypto.py, tools/reference_ssh.py and tools/reference_pairing.py. Install their separate requirements-dev.txt only in a reference environment. Disposable probes stay under ignored docs/temp/.
