ssh-snakehole / 0.2.1 / 7 October 2026

Implementation evidence and audit boundaries

The library now imports its SSH, SFTP, curve, signature, cipher, key-serialization and PAKE implementations. AsyncSSH supplies SSH/SFTP; cryptography supplies key/HKDF operations; PyNaCl supplies authenticated Wormhole phase and vault encryption; spake2 supplies the same PAKE used by Magic Wormhole. wsproto/h11 remain the framing packages. The application owns pairing transcripts, relay rendezvous, temporary process lifetime and transfer publication policy.

All custom cipher and curve code, the SSH packet engine, SFTP packet engine, vendored curve subset, zipapp delivery, bootstrap scripts, PATH editing, install/remove commands and offline installer have been removed. Superseded design documents remain locally in ignored docs/temp.

Verified evidence

All 37 tests pass on Windows x64 and Linux x64 Ubuntu 24.04 in WSL as non-admin users on CPython 3.12.14. Each platform skips one test specific to the other OS. Tests cover public-key authentication and host pin rejection, TCP and fragmented WebSocket workflows, output limits, timed commands, host death and descendants, binary files, no-overwrite collisions, encrypted vaults, cancelled operations and native OpenSSH/SFTP rekeying. The installed CLI is tested from a temporary directory through host, connect, exec, put, get and close. Installed wheel execution uses isolated Python.

Installed packages also pass both roles across Windows and Linux through the public Magic Wormhole mailbox and Transit relays. Each direction verifies binary stdin/stdout, exit status 7, a 51,200-byte upload/download, reconnection and confirmed host closure. Both peers share a physical network; separate-NAT validation remains pending.

Offline pip installation from a wheelhouse is exercised on Windows. Linux installation resolves all dependencies from prebuilt wheels. macOS ARM64/Python 3.12 wheel resolution also succeeds; that is installation evidence, not native macOS runtime validation. CI defines Python 3.11-3.14 on Windows/Linux/macOS but has not run remotely.

The nine runtime dependency distributions were checked with pip-audit on 7 October 2026 with no known vulnerabilities reported. This is a database check, not a security proof. The pinned h11 0.16.0 is the patched version for CVE-2025-43859.

Boundaries

This is a tested early library, not mature production infrastructure or an independently security-audited product. Native macOS, ARM64 runtime, Python 3.11/3.13/3.14, protected admin mode, separate-NAT operation and sustained multi-gigabyte workload evidence remain release gates. Upstream spake2 still uses Python point arithmetic; adopting packages does not create a blanket constant-time guarantee.

Default access requires reachable public relays; there is no direct listener, HTTP proxy or automatic 443 fallback. Commands and SFTP have account-wide rights. There are no PTYs, interactive SSH shells, forwarding or agent forwarding. Host connections are capped at eight, active sessions at sixteen per connection and sixty-four per process. Stream windows are 256 KiB; application transfer chunks are 32 KiB and native SFTP reads are capped at its advertised 4 MiB.

Windows Job Objects and Unix process groups plus a temporary pipe watcher stop ordinary owned descendants. They are not a sandbox against a deliberately hostile operator. Filesystem work finishes before its descriptor is closed on cancellation. Blocking network filesystem calls cannot be forcibly interrupted; local filesystems are the supported boundary.

Transfers publish sibling temporary files through hard-link/no-overwrite or atomic replacement. A lost publication reply means unknown commit state. Confirmed link followed by failed temporary removal reports committed=True. Local link/unlink cancellation can also leave publication unknown. Fsync does not promise directory persistence through power failure.

Native OpenSSH export is explicit plaintext credential export into a newly created private directory. It refuses existing directories and unsafe config paths, cleans partial failures and modifies no global SSH settings. The normal package creates no service, scheduler entry, PATH edit or SSH daemon.

Reproduce

python -m pip install -e . -r requirements-dev.txt
python -m ruff check .
python -m ruff format --check .
python -m mypy
python -m build
python -m unittest discover -s tests -v
python tools/audit_runtime.py

The independent Magic Wormhole peer check is tools/reference_pairing.py with requirements-dev.txt installed. Mypy checks every runtime module body and requires annotated definitions in the public host, client and ticket modules. The only missing-stub exception is upstream spake2. CI checks the installed package with isolated Python. Review logs, wheelhouses and source investigations stay in ignored docs/temp.
