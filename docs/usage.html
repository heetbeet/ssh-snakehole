Open access, share a code, finish, close

Use CPython 3.11-3.14 in an ordinary Python environment. Version 0.2.1 is distributed through the private Auto Actuary index. An index account is required. Pip uses your existing credentials or prompts for them:

python -m pip install https://pypi.autoactuary.com/packages/ssh_snakehole-0.2.1-py3-none-any.whl

For development, install this checkout with python -m pip install .. A venv is optional and managed with Python's standard tools. Installation creates no service or PATH changes.

Agent API

import asyncio
from ssh_snakehole import connect

async def assist(code):
    async with connect(code) as session:
        result = await session.run("COMMAND")
        result.check_returncode()
        print(result.stdout.decode(errors="replace"))
        await session.close_host()

asyncio.run(assist(code))

The API keeps credentials in memory unless explicitly saved. Retain session.ticket to reconnect within the host lifetime. The CLI asks for a ticket passphrase; agents can use SSH_SNAKEHOLE_PASSPHRASE in their secret environment. The original code is consumed. Lost commands are never replayed.

session.exec() exposes AsyncSSH byte streams: read(32768) reads a chunk; read() waits for EOF. Captured run() output defaults to 8 MiB. Commands time out after five minutes unless an explicit timeout is supplied.

Offline installation

Prepare a wheelhouse on matching OS, CPU and Python version:

python -m pip install build
python -m build --wheel
python -m pip download --only-binary=:all: --dest wheelhouse dist/ssh_snakehole-0.2.1-py3-none-any.whl

Copy wheelhouse to the offline computer, then use:

python -m pip install --no-index --find-links wheelhouse ssh-snakehole==0.2.1
python -m ssh_snakehole open

Installation is offline; connecting the two computers still needs a reachable relay.

User and admin access

Default mode refuses an elevated interpreter. Admin mode requires an already elevated terminal, isolated Python and a protected environment including all dependencies: python -I -m ssh_snakehole open --admin. There is no automatic elevation or custom admin installer. Native admin lifecycle validation remains pending.

The default lifetime is two hours. Ctrl+C or host context exit revokes access. Closing stops ordinary owned commands but does not undo their intentional software/file changes. Deliberately detached processes and newly installed persistent services are outside the cleanup promise.

Native SSH and network route

python -m ssh_snakehole export-ssh ID NEW-DIRECTORY exports an unencrypted key and pinned OpenSSH config to a new private directory. Existing directories are refused. Delete it after use. PTYs, shell sessions, forwarding, agent forwarding and legacy SCP are rejected.

Default pairing uses outbound TLS WebSockets. Default Transit uses outbound TCP port 4001. An explicit binary WebSocket relay can be supplied where that port is blocked. Both sides authenticate the Transit greeting and establish SSH with pinned keys obtained through PAKE.
