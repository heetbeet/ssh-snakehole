connect and resume open PowerShell on Windows or the account's shell on Unix. Its prompt, working directory, variables, profiles, interactive Python, Ctrl+C, colors and resizing use a real SSH terminal. Windows PTYs require Windows 10 1809 or later. Type exit to disconnect; use the separate local close command to revoke access. Host Ctrl+C revokes immediately. Multiple controllers may share accepted credentials; separate open invocations are independent.

Connection setup tries ICE with local and STUN-discovered addresses. When UDP punching succeeds, SSH runs over a reliable, ordered WebRTC data channel. Otherwise it uses the existing relay. Connection details show direct-udp or relay. Some routers change ports between destinations and some networks block UDP; direct routing is not guaranteed. Setup may take several seconds. Keep the same Python Session for repeated work.

A reachable Transit relay is still needed for encrypted connection negotiation. Default STUN is stun.l.google.com:19302. Before the subcommand, --stun stun:HOST:PORT selects another server; --stun none gathers local addresses only. No router settings or global firewall rules are changed.

Recovery

The encrypted ticket is saved and its token printed before initial SSH setup. If that setup fails, use resume with the token. pair returns the token without dialing SSH; first authentication must follow within two minutes. For the API, ConnectTimeout and RelayUnavailable carry the accepted ticket in error.ticket.

If an established connection breaks, reconnect using the token or session.ticket. Each new connection tries ICE again and may fall back to relay. There is no transport switch or command replay within an established SSH connection. OutcomeUnknown means an interrupted command has no confirmed result: inspect its effects before retrying. File publication and remote close can also remain unconfirmed after a lost reply. Both peers need 0.5.0; create a fresh invitation after upgrading. Earlier tickets are not converted.

Inactivity and long work

Access expires after 30 minutes of inactivity. Commands, open interactive shells and open regular-file transfers pause the host timer. The full interval starts after the last active operation finishes, including nonzero command exits. Long silent commands have no implicit timeout. --timeout on exec is optional. An optional host --lifetime SECONDS is a hard limit that overrides active work; no hard lifetime is imposed by default.

Authenticated keepalive renews inactivity; so does a normal completed command such as echo keepalive. Idle transports, cached SFTP channels without open files and automatic SSH keepalives do not. A controller must stop its foreground keepalive process when finished. No service or detached process is installed.

Agent input and API

Prefer the importable connect(code) context and retain its Session for repeated run/run_argv/exec/put/get calls. API credentials remain in memory unless explicitly saved. session.exec exposes byte streams; read(32768) reads a chunk and read() waits for EOF. session.keepalive renews access without a remote shell command. Captured run output defaults to 8 MiB. Lost commands are never replayed.

For separate CLI processes, run pair CODE, capture its stdout token, then use exec --token TOKEN and other follow-up commands. For lower exposure to history, process listings and logs, omit credentials for hidden prompts or supply them through --code-stdin / --token-stdin from a trusted runner. exec accepts command input after the token line. CODE is one-use, but can be raced before redemption. The reconnection token stays usable while access remains open.

The token contains 256 random bits, independent of CODE, and unlocks the owner-protected encrypted ticket on this computer. Neither secret is stored as plaintext. Another computer needs both token and ticket. Malware controlling your account can still capture live credentials.

session.terminal() opens a real remote shell. An optional command starts an interactive program. It exposes byte input/output, resize(columns, rows) and wait(). PTY stdout and stderr share one stream; session.exec() keeps them separate. Ctrl+C is the byte 0x03 on a terminal stream.

Terminal encoding

SSH carries bytes and does not negotiate text encoding. Windows ConPTY uses UTF-8, so use a UTF-8 remote locale when connecting from Windows. Unix PTYs preserve bytes, including Latin-1; the application, locale and local terminal must agree. All exec streams preserve binary data on every platform. The API leaves decoding to the caller.

Colors and full-screen applications use VT sequences and TERM. Use a current terminal such as Windows Terminal and a font with the required characters. Windows input is translated to portable VT keys. Open shells count as active work, even while an application waits for input.

Native SSH

export-ssh --token TOKEN NEW-DIRECTORY and exports an encrypted OpenSSH private key, pinned known-hosts file, config and route metadata. It refuses existing directories and unsafe config paths. Run the printed ssh command; OpenSSH asks for the same token as its private-key passphrase. Route metadata contains no operator private key. The Python API is simpler for agents. No global SSH settings are changed. The printed ssh command opens a shell; add a command for execution. OpenSSH -tt forces a PTY. Port forwarding, agent forwarding and legacy SCP are not provided; SFTP is supported.

Offline installation

Prepare on matching OS, CPU and Python:

python -m pip install build
python -m build --wheel
python -m pip download --only-binary=:all: --dest wheelhouse dist/ssh_snakehole-0.5.0-py3-none-any.whl

Copy wheelhouse to the offline computer:

python -m pip install --no-index --find-links wheelhouse ssh-snakehole==0.5.0

Installation is offline; pairing and SSH still require a reachable relay.

Admin and cleanup

Default mode refuses elevation. Admin mode requires an already elevated terminal, isolated Python and a protected installation including all dependencies: python -I -m ssh_snakehole open --admin. There is no automatic elevation or custom installer. Protected admin lifecycle validation remains pending.

Close stops ordinary owned commands, but intentional file/software changes remain. Deliberately detached processes and newly installed services are outside cleanup. Encrypted tickets can remain after remote inactivity expiry; forget removes them. Invitations expire after ten minutes and first SSH authentication must follow pairing within two minutes.

Default pairing uses outbound TLS WebSockets and Transit uses outbound TCP 4001. ICE opens temporary UDP sockets, performs authenticated connectivity checks and uses STUN for address discovery. Those sockets close with their SSH session. An explicit binary WebSocket relay can be supplied where that port is blocked. Both sides establish SSH using the pinned identities obtained through SPAKE2.
